# CodeSnag Privacy Policy

**Effective date:** November 11, 2026
**Owner:** Abdur Rahman Khan — ARK Ecosystem
**Contact:** arkmfk27@gmail.com

## Short version
CodeSnag collects nothing. Your code snippets are stored only in your own browser, on your own device. Nothing is sent to any server. There is no server, no account, no sign-in, no analytics, no tracking, and no advertising.

## What CodeSnag stores — and where
- Your saved snippets (title, code, language, shortcut, tags, source page title and URL, dates) are stored only in your browser's local extension storage (`chrome.storage.local` / the Edge equivalent).
- Your settings (insert trigger character, on/off toggles, disabled sites) are stored in the same local storage.
- Nothing is stored anywhere else. CodeSnag does not use cloud storage, does not sync, and does not back up your data unless you choose to export it yourself.

## What CodeSnag does NOT collect
- No personal data, no name, no email, no browsing history.
- No code you save, no code you search for, no code you insert.
- No analytics, usage statistics, crash reports, device identifiers, or location.
- No advertising data, and no data is sold or shared with anyone.

## Network
CodeSnag makes no network requests. It does not contact any server, including the developer's. The only time your data leaves the browser is when you yourself press Export (a JSON file is downloaded to your device) or Import (a JSON file you choose is read into the extension).

## Permissions — why each one is needed
- **storage** — to save your snippets and settings locally in the browser.
- **activeTab** — to read the code you choose to save from the page you are on.
- **contextMenus** — to add “Save selection to CodeSnag” to the right-click menu.
- **Host access (google.com, stackoverflow.com, github.com, and other sites)** — to show the “Save to CodeSnag” button on code blocks, to show your own saved snippets on Google search results, and to let the `/shortcut` insert work in text boxes on the sites you use. Host access is used only for those features, on your device.

## Your own saved snippets on Google search
When a Google search matches the title or text of a snippet you already saved, CodeSnag shows a card with that snippet at the top of the results. Only your own snippets are shown. No search query is sent anywhere by CodeSnag.

## Uninstall
If you uninstall CodeSnag, the browser deletes its local storage, including your snippets. Export a JSON backup first if you want to keep them.

## Children
CodeSnag is not directed at children under 13 and collects no data from anyone.

## Changes to this policy
If this policy changes, the new version will be published at this same page with a new effective date. Because CodeSnag collects no contact details, we cannot notify you directly — please check this page when you update.
